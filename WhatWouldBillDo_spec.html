App Icon Concept

A single candle flame — warm amber glow on a cream/parchment background. Simple, centered, hopeful. The candle represents the single light that stays lit even in the darkest moment — the reason someone picks up the phone at 3am instead of reaching for the bottle.

Background: aged parchment (#F0E3B8 gradient). Flame: warm amber (#C8860A) to gold (#FFD166) with soft glow. The flame should be hand-drawn in style — not glossy, not geometric. Like it was sketched by someone in recovery.

No text. No AA symbol (trademark risk). No sobriety counter aesthetic. Just the candle.

📌 API Key Strategy

The iOS app does NOT include the Anthropic or OpenAI API keys. It calls YOUR FastAPI backend, which holds the keys on Railway. This is correct — never ship API keys in an iOS app. The Railway backend is the secure layer. Consider adding a simple API key header from the iOS app to the backend (e.g., X-App-Key) to prevent unauthorized direct calls to your Railway endpoint.

💡 Pricing Rationale (CalAI Model Research)

CalAI ($4.99/wk, $12.99/mo, $49.99/yr) gates its core feature — the food photo analyzer — behind a hard paywall after 2 free uses. WWBD mirrors this: 3 free "Ask Bill" conversations (enough to feel the magic), then gate. The weekly option catches impulsive converts. Monthly is the main volume driver. Yearly is the high-LTV trophy. At $59.99/yr, WWBD is priced below I Am Sober ($84/yr) and less than half of Reframe ($140/yr) while delivering something neither offers: actual wisdom on demand. Blended ARPU estimate: ~$42/year. At 1,000 subscribers = $42K ARR. Cost per subscriber (Claude Haiku): ~$0.30/month = $3.60/yr. 91% margin at scale.

Conversion Trigger Logic

// In ChatViewModel
let FREE_CONVERSATIONS = 3

func canSendMessage() -> Bool {
    if subscriptionManager.isSubscribed {
        return true
    }
    let used = UserDefaults.standard
        .integer(forKey: "freeConvosUsed")
    return used < FREE_CONVERSATIONS
}

func onMessageSent() {
    let used = UserDefaults.standard
        .integer(forKey: "freeConvosUsed")
    UserDefaults.standard.set(used + 1,
        forKey: "freeConvosUsed")
    if used + 1 >= FREE_CONVERSATIONS {
        // Trigger Superwall
        Superwall.shared
            .register(event: "bill_limit_reached")
    }
}

Section 06

Known Gotchas

Every one of these will cost you an hour if you hit it cold. Read before starting each session.

⚠️ Swift 6 Strict Concurrency — S1
Enable SWIFT_STRICT_CONCURRENCY = complete in build settings. All @Observable classes that are accessed across actor boundaries need @MainActor or explicit nonisolated. ChatViewModel should be @MainActor since it updates UI state.
⚠️ xcodegen — Always regenerate after adding files — S1, S2...
Every time you add a new .swift file, run xcodegen generate. Xcode won't see the file otherwise. Add an alias: alias xg='xcodegen generate && open *.xcodeproj'
⚠️ SwiftData @Model cannot have computed properties with certain types — S1
Don't put computed properties or complex types directly in @Model classes. Store only primitives and simple structs. For citations: [String], store as JSON string in SwiftData and decode when needed, OR upgrade to iOS 17.4+ SwiftData where arrays of Codable are supported.
⚠️ StoreKit 2: No #if DEBUG purchase bypass — S3
Never bypass the verification step. Always use the .verified(let transaction) pattern. The StoreKit .storekit configuration file handles sandbox testing without code changes.
⚠️ WidgetKit: containerBackground is required in iOS 17 — S7
Use .containerBackground(for: .widget) { Color("ParchmentBackground") } instead of .background(). Failing this causes the widget background to appear system-default (transparent/dark) on iOS 17+.
⚠️ App Group must be on BOTH targets — S7
The widget extension target needs the same App Group capability as the main app target. Check both in Signing & Capabilities. Forgetting this means UserDefaults(suiteName:) returns nil silently.
⚠️ Superwall must be configured before first view appears — S6
Call Superwall.configure() in App.init(), before any SwiftUI views render. Configuring it in onAppear causes race conditions.
⚠️ API timeout — network calls from SwiftUI — S2, S5
Bill responses take 2-8 seconds depending on load. Set URLSession timeout to 30s minimum. Show a "Bill is reflecting..." state immediately after sending to prevent user anxiety. Never disable the send button without showing feedback.
⚠️ Privacy Manifest (PrivacyInfo.xcprivacy) required — S10
Apple rejects apps that use UserDefaults without a privacy manifest declaring it. Add PrivacyInfo.xcprivacy to the main target (not just the widget). Required NSPrivacyAccessedAPIType: NSPrivacyAccessedAPICategoryUserDefaults with reason CA92.1 (app functionality).
⚠️ Conversation history size — S5
The FastAPI /ask endpoint accepts conversation_history. Keep this to the last 6 exchanges (12 messages) max on the iOS side, or you'll hit the model context limit and API will error. Truncate history before sending.
⚠️ Copyright — NEVER mention Twelve & Twelve or As Bill Sees It — All Sessions
The iOS app must not reference, quote, or display content from Twelve Steps and Twelve Traditions (1952) or As Bill Sees It (1967). These are copyrighted by AAWS. The corpus only contains public domain materials. If Bill's AI response ever cites these, it's a backend prompt issue — do not display the citation.
⚠️ Force light mode in root — S1
Add .preferredColorScheme(.light) to the root WindowGroup content. The parchment design only exists for light mode in v1. Dark mode theming is a v1.1 task.
